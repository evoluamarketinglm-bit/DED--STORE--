# DEDÉ STORE — Landing Page

Projeto para publicar na raiz do GitHub Pages ou Vercel (arquivos da raiz do ZIP).

- Cabeçalho preto conforme referência: logo à esquerda, menu e busca à direita, Instagram e WhatsApp em dois botões abaixo.
- Links dos botões: Instagram `https://www.instagram.com/dede.31.01/` e WhatsApp `https://wa.me/5564993374991`.
- Cards dos escudos mais compactos, mantendo o diâmetro das bolinhas e o carrossel automático.
- Sem banner principal superior, conforme a versão fornecida.
- Coleções, banners, escudos, links de catálogos e botão flutuante preservados.
- Correção para que a ausência do banner superior não interrompa o JavaScript do cabeçalho.

Personalize contatos, imagens e links em `configuracao.js`.
